# STEPビューア（Chrome拡張）

STEP/STP/IGES/BREPファイルをブラウザ内で解析して3D表示する Chrome 拡張（Manifest V3）。
解析には occt-import-js（OpenCascade の WASM 版）、描画には three.js を同梱しています。
通信は一切しません。開いたファイルが外部に送信されることはありません。

## インストール（パッケージ化されていない拡張機能として読み込む）

1. このフォルダを Windows 側の任意の場所に置く（zip の場合は先に展開する）
2. Chrome で `chrome://extensions` を開く
3. 右上の「デベロッパーモード」を ON
4. 「パッケージ化されていない拡張機能を読み込む」→ このフォルダを選択
5. ツールバーに拡張アイコンが現れる（ピン留め推奨）。クリックするとビューアのタブが開く

更新時（フォルダの中身を差し替えた時）は、`chrome://extensions` でこの拡張の再読み込みボタンを押せば反映されます。

## 使い方

- ビューアのタブへ STEP ファイルをドラッグ＆ドロップ、または「ファイルを開く」から選択
- 対応形式: .step / .stp / .iges / .igs / .brep
- 操作: 左ドラッグ=回転、ホイール=ズーム、右ドラッグ=パン
- 視点ボタン（斜め/上面/正面/右側面）、ワイヤーフレーム、エッジ、グリッド、自動回転
- 分割精度を変えると再解析します（細かい=曲面が滑らか、粗い=速い）
- 外形寸法・メッシュ数・三角形数・中心座標を右ペインに表示

## 自動起動（Markdown Viewer 方式）

対応拡張子のファイルへ Chrome で移動すると、ビューアが自動で引き継いで表示します。

- ファイルを Chrome のウィンドウへドロップして開く、file:// で開く、Web 上の STEP リンクをクリックする、が対象です
- **file:// を使う場合は追加設定が必須**: `chrome://extensions` → STEPビューア →「詳細」→「ファイルの URL へのアクセスを許可する」を ON
- MV3 の制限で、対象ファイルのダウンロードが同時に始まってしまう場合があります（その場合はダウンロード側を消してください）

## ローカルファイルについて

- ファイル選択とビューアへのドラッグ＆ドロップでも開けます。OneDrive の同期フォルダなど、ローカルに実体があるファイルはそのまま開けます
- ブラウザのセキュリティ上、拡張が勝手に任意のパスを読むことはできません（自動起動時も、開く対象は Chrome が移動しようとした URL に限られます）
- OS 側で .step のダブルクリックにこの拡張を関連付けることはできません（Chrome 拡張の仕様）

## 技術メモ

- occt-import-js は内部（Embind）が `Function` コンストラクタで関数を生成するため、MV3 の拡張ページ CSP では動きません（'unsafe-eval' は拡張ページで許可されない）。そのため解析処理は MV3 のサンドボックスページ（sandbox.html）に隔離し、メッシュ配列だけを postMessage で受け渡しています
- サンドボックスは opaque origin で動くためパッケージ内の .wasm を自分で fetch できません。wasm バイナリは拡張ページが fetch し、postMessage でサンドボックスへ渡して `wasmBinary` として初期化します（v1.1.1）

## 構成

- manifest.json / background.js（アイコンクリックでビューアタブを開く＋ナビゲーションの横取り）
- viewer.html / viewer.css / viewer.js（描画 UI）
- sandbox.html / sandbox.js（解析専用サンドボックス）
- vendor/: three.min.js (r128), OrbitControls.js, occt-import-js.js / .wasm (0.0.23)
